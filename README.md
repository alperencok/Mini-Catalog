# Mini Catalog - Flutter E-Commerce App

A cross-platform mobile shopping catalog application built with Flutter and Material Design 3, fetching items live from the Fake Store API.

## Features

- **Product Catalog:** Grid layout displaying product images, titles, prices, categories, and ratings.
- **Search & Categories:** Search products by name and filter by category (Electronics, Jewelery, Men's Clothing, Women's Clothing).
- **Product Details:** Dedicated detail screen with product descriptions and quantity selection.
- **Cart Management:** Add to cart, adjust quantities, remove items, and view total price calculation.
- **Checkout Dialog:** Order confirmation modal with cart auto-reset.

## Tech Stack

- Flutter SDK (Material 3)
- Dart
- `http` package for REST API calls
- FakeStoreAPI

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alperencok/Mini-Catalog.git
   cd Mini-Catalog
   ```

2. Fetch dependencies:
   ```bash
   flutter pub get
   ```

3. Run the application:
   ```bash
   flutter run
   ```
